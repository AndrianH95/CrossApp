## Предметна область: Замовлення

Призначення: Оформлення замовлень покупців, формування специфікацій та підрахунок підсумкової вартості.

Основні сутності:
* Customer — Клієнт (покупець)
* Product — Товар / послуга
* Order — Замовлення
* OrderLine — Рядок замовлення (позиція товару та кількість)
